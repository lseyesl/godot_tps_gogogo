# 游戏设计术语表

本文档只记录访谈中已经确认的领域概念；规则未确定时会明确标注。

| 术语 | 当前定义 |
| --- | --- |
| 玩家 | 单人 PvE 模式中由用户控制的角色。 |
| 隔板 | 用于分割平面地形并阻挡移动、射击和视野的场景物体。 |
| 可损坏隔板 | 能被直接伤害或环境反应移除的隔板；首版包括木墙、石油滚筒墙和汽油滚筒墙。 |
| 不可损坏隔板 | 不会被首版任何武器或环境反应移除的隔板。 |
| 砖墙 | 首版唯一不可损坏的隔板，用于构成地图的稳定结构骨架。 |
| 木墙 | 可被枪弹或爆炸逐步破坏的隔板。 |
| 石油滚筒墙 | 点燃后持续燃烧并最终消失的可损坏隔板。 |
| 汽油滚筒墙 | 受到足够伤害或火焰作用后爆炸并消失的可损坏隔板。 |
| 默认手枪 | 玩家默认持有的单发武器。 |
| 地图武器 | 随机出现在地图中的可拾取枪械；首版包括手枪、机枪和火箭枪。 |
| 受限视野 | 玩家只能看见一定范围内且未被障碍物遮挡的内容；表现与判定方式待确认。 |
| 关卡清剿 | 已取消的旧胜利条件；当前不要求消灭全部敌人。 |
| 失败 | 玩家死亡时，本局立即失败。 |
| 预置敌人 | 关卡开始时已经确定位置的敌人；首版战斗中不会新增敌人或出现增援。 |
| 声源位置 | 枪声或爆炸发生的位置；被惊动的敌人可前往调查，但不会借此持续获知玩家位置。 |
| 最后已知位置 | 敌人最后一次目击玩家的位置；丢失视线后，敌人会以此为中心进行短暂搜索。 |
| 有效视线 | 玩家当前能实际获得信息的区域，同时受观察距离和障碍物遮挡限制。 |
| 视线外单位 | 摄像机可能覆盖、但不处于玩家有效视线内的敌人或拾取物；首版不会向玩家显示。 |
| 移动摇杆 | 屏幕左侧的虚拟摇杆，用于控制玩家角色移动。 |
| 朝向摇杆 | 屏幕右侧的虚拟摇杆，用于独立控制玩家角色朝向。 |
| 射击键 | 位于屏幕右侧的开火按钮；按下立即开火，按住拖动可在持续射击时调整射击方向。 |
| 瞄准虚线 | 常驻的弹道辅助线；最长 8 个模块，在首个阻挡物处截断，空闲时淡显、操作或射击时高亮。 |
| 轻度瞄准辅助 | 对有效视线内且靠近瞄准线的敌人进行小幅方向修正；不透墙、不自动开火。 |
| 120° 扇形视野 | 以角色朝向为中心、向左右各展开 60° 的玩家视野；具有有限半径并受障碍物遮挡。 |
| 盲区 | 位于玩家扇形视野之外，或被障碍物遮挡的不可见区域。 |
| 暗化地形 | 盲区中仍然显示、但降低亮度和饱和度的静态地图结构。它不表示玩家能看到其中的动态威胁。 |
| 攻击暴露 | 敌人射击后触发的临时显形状态，持续 2 秒并在每次射击时刷新。它只高亮攻击者，可绕过玩家的朝向盲区，但不能穿透实体障碍物或揭示周围内容。 |
| 最后暴露位置 | 攻击暴露中的敌人进入墙后留下的静止位置提示；它不会继续追踪敌人的移动。 |
| 手枪警卫 | 首个可玩版本的唯一敌人类型；装备与玩家相同的标准默认手枪，能够巡逻、听声调查、寻找掩体、单发射击并搜索最后已知位置。 |
| 生命格 | 玩家耐久单位；玩家上限为 5 格，手枪警卫每次命中扣除 1 格。 |
| 急救包 | 每局生成两个的有限恢复物；玩家受伤时靠近会自动拾取并恢复 2 格，满生命时不会消耗。 |
| 拾取武器槽 | 默认手枪之外的单一武器槽；拾取新的特殊武器时会替换槽中的旧武器。 |
| 重型手枪 | 地图随机生成的有限弹药武器；比永久默认手枪伤害更高，射程相同，并占用拾取武器槽。 |
| 敌人生命点 | 手枪警卫的耐久单位；满生命为 3 点，默认手枪每次命中造成 1 点伤害。 |
| 自动换弹 | 当前弹匣打空后自动执行的换弹过程；换弹期间不能射击，首版没有手动换弹键。 |
| 武器拾取物 | 地图中随机出现并自带固定弹药的武器；同类拾取用于补充弹药，不同类拾取用于替换拾取武器槽。 |
| 掉落武器 | 从拾取武器槽中被替换后落在玩家脚下的武器；保留剩余弹药并可再次拾取。 |
| 交换按钮 | 玩家靠近不同类型武器时出现的临时确认按钮；点击后才替换拾取武器槽。 |
| 即时射线命中 | 开火瞬间沿瞄准方向判定首个碰撞目标的弹道模型，用于两类手枪和机枪。 |
| 实体火箭 | 在场景中飞行、可被观察和躲避，并在碰撞墙体或角色时引爆的火箭弹。 |
| 持续伤害区 | 燃烧中的石油滚筒墙所形成的危险区域，会同时伤害进入其中的玩家和敌人。 |
| 邻接传播 | 火焰只能点燃直接接触的木墙、石油滚筒墙或汽油滚筒墙；不能跨越间隙或砖墙。 |
| 耐久触发 | 隔板受到确定性伤害并在耐久归零时进入燃烧、爆炸或破坏状态的规则；不包含随机触发概率。 |
| 无阵营爆炸 | 同时伤害玩家、敌人和可损坏隔板的范围效果；伤害随距离衰减，并可触发滚筒墙连锁反应。 |
| 隔板模块 | 构成墙体或滚筒墙的最小独立单位；拥有自己的状态，被移除后只开放对应位置。 |
| 候选出生点 | 手工放置并验证过的位置；敌人、武器和急救包会从对应类型的候选点中随机生成。 |
| 单关目标时长 | 玩家从进入地图到完成清剿的预期时间；首版设定为 5–8 分钟。 |
| 敌人预算 | 每关开局预置的手枪警卫数量；首版为 8–12 名。 |
| 剩余敌人数 | 战斗界面持续显示的威胁参考，只表示仍存活的敌人数量，不显示位置，也不是通关条件。 |
| 任务点 | 玩家在去程中需要找到并激活的关卡目标；激活后所有存活警卫进入警戒。 |
| 撤离点 | 与玩家出生点相同的位置；任务点激活后返回此处即可完成关卡，无需全灭敌人。 |
| 撤离阶段 | 任务点完成 3 秒激活后开始的关卡阶段；所有存活警卫进入警戒，玩家需要返回出生点。 |
| 全体警戒 | 任务激活后所有存活警卫进入的状态；它们获知任务点位置，但不会获得玩家的实时坐标。 |
| 即时撤离 | 任务点激活后，玩家进入出生点撤离范围便立即完成关卡，不需要第二次读条。 |
| 首版地图 | 首个可玩版本唯一的一张手工地图；通过随机选择候选点改变每局内容分布。 |
| 本局随机种子 | 决定敌人、任务点和物资初始位置的数据；死亡重试时保留，新游戏时重新生成。 |
| 标准难度 | 首个可玩版本唯一的难度档；不向玩家提供难度选择。 |
| 视野半径 | 120° 玩家视野从角色向外延伸的最大距离；CQB 基准为 5.5 个隔板模块（约 11 米）。 |
| 固定镜头方位 | 镜头跟随玩家位置但不随角色转向旋转，地图在屏幕上的方向保持稳定。 |
| 独立移动与瞄准 | 左摇杆控制屏幕方向移动，右侧输入独立控制朝向；角色可向任意方向同速移动并向另一方向射击。 |
| 基础移动 | 首版玩家唯一的移动状态；没有冲刺、翻滚或蹲伏。 |
| 统一武器射程 | 玩家全部武器与敌方手枪的最大直接射程均为 5 个隔板模块（约 10 米），比双方视野半径短 1 个模块（2 米）。 |
| 对称视野 | 玩家与手枪警卫共同使用的 120°、5.5 模块半径、受障碍遮挡的视觉规则。 |
| 首次攻击预警 | 警卫首次发现玩家后的 0.6 秒转向、举枪和方向性警戒声；结束后才能射出第一发。 |
| 武器定义 | 集中保存武器伤害、射程、射击间隔、弹匣和换弹规则的数据；不从属于某一种警卫。 |
| 警卫配置 | 将感知与战术行为和一把武器组合起来的敌人配置；后续可通过更换武器扩展敌人类型。 |
| 共享武器数值 | 同名武器不因玩家或敌人持有而改变伤害、射程、射速、弹匣或换弹时间。 |
| 敌人掉落 | 首版手枪警卫死亡后不生成武器拾取物。 |
| 首轮武器基准 | 用于第一个可玩原型的初始伤害、弹匣、射速与换弹数值；需要通过真机测试继续调优。 |
| 隔板耐久基准 | 木墙 5 点、石油滚筒 4 点、汽油滚筒 3 点；砖墙无限耐久。 |
| 燃烧基准 | 石油滚筒燃烧 4 秒、木墙燃烧 3 秒；火区每秒造成 1 点无阵营伤害，离开后不持续灼烧。 |
| 爆炸遮挡 | 完整隔板阻挡本次爆炸对墙后目标的伤害；即使墙在本次结算中被摧毁，爆炸也不会继续穿透。 |
| 汽油桶爆炸基准 | 半径 1.5 模块、爆心 3 点、边缘 1 点的无阵营范围伤害，能够触发相邻滚筒但弱于火箭。 |
| 无击退爆炸 | 首版爆炸只结算伤害、破坏和连锁，不推动任何角色或物体。 |
| 特殊武器预算 | 每局生成四件特殊武器：重型手枪、机枪、火箭枪各一件，另加一件随机重复武器。 |
| 目标指示器 | 屏幕边缘显示的目标方向与大致距离提示；不提供路径，也不揭示沿途动态内容。 |
| 横屏布局 | Android 首版唯一支持的屏幕方向；左侧移动、右侧瞄准与射击，中央显示战场。 |
| 纯平面玩法 | 使用 3D 画面，但移动、寻路、视野和射击核心判定都发生在单一水平面，不包含高低差。 |
| 技术底座 | 首版采用 Godot 4 与 Mobile 渲染器，首要导出平台为 Android。 |
| 性能目标 | 中端 Android 默认稳定 60 FPS，并提供锁定 30 FPS 的省电选项。 |
| 声音事件 | 带有声源位置与听觉半径的游戏事件；警卫可前往调查，但不会获得玩家实时坐标。 |
| 刺激优先级 | 警卫选择行动线索的顺序：目视玩家、受击方向、最后已知位置、最高强度新声音、巡逻。 |
| 有效掩体 | 警卫 3 模块内、可到达且能阻挡玩家直线射击的位置；燃烧或即将爆炸的隔板不算有效。 |
| 破坏更新 | 模块消失后，碰撞、射击和视线同帧更新，警卫路径最迟在 0.2 秒内更新。 |
| 格子路径图 | 与隔板模块对齐的二维通行数据；墙体存在时阻塞，墙体移除时开放，警卫在 3D 中沿路径移动。 |
| 世界模块 | 2×2 米的基础水平尺寸，同时用于隔板宽度和寻路格；角色碰撞直径约 0.8 米。 |
| 地图尺寸基准 | 首版地图约 30×20 模块，即 60×40 米，包含 6–8 个区域。 |
| 移动速度基准 | 玩家 4.5 m/s；警卫巡逻 2.5、调查 3.2、追击 4.0 m/s。 |
| 临时阻塞格 | 因火焰等短期危险而被警卫寻路视为不可通行的格子；危险结束后重新开放。 |
| 射击方向锁定 | 警卫每发开枪前最后 0.2 秒停止跟踪玩家，射线沿固定方向发出。 |
| 战绩结算 | 通关后展示本局用时、击杀数、剩余生命与撤离结果；不会发放永久成长资源。 |
| 武器切换图标 | HUD 右上角的默认手枪与特殊武器按钮；点击切换，特殊武器耗尽时自动回到默认手枪。 |
| 半自动触控 | 两类手枪与火箭每次按下只发射一发，必须松开并重新按下才能再次射击。 |
| 全自动触控 | 机枪在射击键按住期间按武器射速持续开火，松开后停止。 |
| 保持朝向 | 右侧瞄准输入松开后，角色、视野扇形和枪口保持最后方向，不随移动自动旋转。 |
| 盲区间接反馈 | 墙后火焰和爆炸不显示精确特效，只通过方向性声音和可见表面受光提示发生过环境事件。 |
