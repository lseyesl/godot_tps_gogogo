# ADR-062：警卫刺激处理优先级

- 状态：已确认
- 日期：2026-08-25

## 决策

警卫同时拥有多个行动线索时，使用以下优先级：

1. 当前视野内的玩家。
2. 刚刚命中自己的伤害来源方向。
3. 玩家最后已知位置。
4. 听觉范围内最近发生的最高强度声音。
5. 原巡逻任务。

低优先级事件不能打断高优先级状态。例如，正在直接看见玩家的警卫不会因远处爆炸而放弃交战。

## 设计理由

使警卫行为在复杂枪声、爆炸和视线变化中保持可解释性，并避免低价值环境事件破坏正在进行的战斗。

## 尚未决定

- 受击但未看到玩家时的搜索持续时间
- 当前目标失效后如何恢复被中断任务
