# ADR-067：首版地图为三十乘二十模块

- 状态：已确认，尺寸待可玩测试调优
- 日期：2026-08-25

## 决策

- 首版唯一地图的目标占地约为 30×20 个世界模块。
- 按每模块 2 米计算，地图水平尺寸约为 60×40 米。
- 地图内部划分为 6–8 个房间、通道或战斗区域。
- 任务点远端候选位置与出生点之间的可行走最短路径至少为 18 个模块。
- 地图需要容纳 8–12 名警卫、4 件特殊武器与 2 个急救包的候选点随机分布。

## 设计理由

在 5–8 分钟目标时长内提供足够探索、遭遇和路线变化，同时避免一张首版地图过度膨胀。

## 尚未决定

- 各区域的具体连接关系
- 砖墙、木墙和两类滚筒墙的面积占比
- 出生点与各类候选点的安全距离
