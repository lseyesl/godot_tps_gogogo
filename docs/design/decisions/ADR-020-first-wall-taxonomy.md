# ADR-020：首版隔板分为四种

- 状态：已确认
- 日期：2026-08-25

## 决策

首版包含以下隔板：

| 隔板 | 是否可损坏 | 核心行为 |
| --- | --- | --- |
| 砖墙 | 否 | 固定地图结构，永久阻挡移动、射击和视野。 |
| 木墙 | 是 | 受到枪弹或爆炸伤害后逐步破坏。 |
| 石油滚筒墙 | 是 | 被点燃后持续燃烧，之后消失。 |
| 汽油滚筒墙 | 是 | 受到足够伤害或火焰作用后爆炸，之后消失。 |

## 设计理由

- 砖墙确保地图始终保留不可绕过的结构骨架。
- 三种可损坏隔板分别提供直接破坏、延迟燃烧和瞬间爆炸三类互动。

## 尚未决定

- 各隔板耐久值与不同伤害类型的效果
- 燃烧是否伤害角色或传播到相邻隔板
- 汽油滚筒墙爆炸的伤害、半径与连锁规则
- 隔板破坏后对寻路和视野的更新时间
