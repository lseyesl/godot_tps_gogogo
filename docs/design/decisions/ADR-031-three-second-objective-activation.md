# ADR-031：任务点在范围内自动激活三秒

- 状态：已确认
- 日期：2026-08-25

## 决策

- 玩家进入任务点范围后自动开始 3 秒激活读条。
- 首版不为任务点增加单独的交互按钮。
- 激活期间玩家仍可转向与射击。
- 玩家离开任务点范围时，激活进度重置。
- 玩家受到伤害不会重置激活进度。
- 读条完成后，任务点立即激活，所有存活警卫进入警戒，关卡进入撤离阶段。

## 设计理由

提供一个短暂的站位风险窗口，同时保持 Android 控件简洁，并避免少量盲区伤害反复打断进度造成挫败。
