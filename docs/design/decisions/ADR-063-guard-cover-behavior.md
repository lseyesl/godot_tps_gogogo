# ADR-063：警卫优先使用附近有效掩体

- 状态：已确认
- 日期：2026-08-25

## 决策

- 警卫看见玩家后，优先搜索自身 3 个模块内的候选掩体。
- 合格掩体必须能够阻挡玩家到警卫位置的直接射线。
- 警卫选择距离最近且可到达的合格掩体。
- 到达掩体后，警卫周期性侧身探出并使用所持武器射击。
- 附近没有合适掩体时，警卫保持约 4–6 模块距离并横向移动。
- 燃烧中的隔板和即将爆炸的汽油滚筒不能作为候选掩体。

## 设计理由

让警卫实际使用地图隔板并对环境危险作出基本判断，同时为无掩体区域提供可预测的替代行为。

## 尚未决定
