# ADR-006：Android 与双摇杆触控优先

- 状态：已确认
- 日期：2026-08-25

> 2026-08-28 更新：右侧瞄准与射击的冲突解决方案已由 ADR-078 的“射线选敌后持续锁定”取代；本 ADR 其余 Android 横屏、左摇杆移动和右侧独立射击键边界继续有效。

## 已确认决策

- 首版优先支持 Android。
- 屏幕左侧使用虚拟摇杆控制角色移动。
- 屏幕右侧使用虚拟摇杆控制角色朝向。
- 屏幕右侧另设独立射击键。
- 从当前枪械的枪口向瞄准方向延伸一条虚线，作为瞄准辅助。
- 右摇杆负责平时观察和预瞄。
- 按下射击键时立即开火；按住射击键并拖动，可以在持续射击期间调整角色朝向与射击方向。

## 已解决的触控冲突

常规双拇指操作下，右拇指无法同时控制右摇杆和独立射击键。通过让射击键同时支持拖动调向，玩家可用一个右拇指完成持续瞄准射击。

## 尚未决定

- 是否提供瞄准辅助
- 瞄准虚线是否会被障碍物截断
- UI 尺寸、位置与可配置规则
