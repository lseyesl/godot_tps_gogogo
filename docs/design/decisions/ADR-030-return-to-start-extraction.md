# ADR-030：出生点同时作为撤离点

- 状态：已确认
- 日期：2026-08-25

## 决策

- 玩家出生点同时是本关撤离点。
- 任务点从地图远端多个经过验证的候选位置中随机选择。
- 玩家必须先深入地图激活任务点，再返回出生位置撤离。

## 设计理由

- 规则直观，玩家天然知道完成任务后应返回哪里。
- 去程允许玩家侦察并规划撤退路线。
- 回程会经过已经被开墙、燃烧或爆炸改变的地图，形成不同于去程的战术状态。
- 随机选择远端任务点可增加路线变化，同时维持手工地图的可验证性。

## 尚未决定

- “远端”候选点与出生点的最短路径距离
- 任务点激活交互
- 撤离是否触碰即完成或需要停留
