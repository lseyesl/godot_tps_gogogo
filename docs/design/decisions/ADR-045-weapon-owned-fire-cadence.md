# ADR-045：射击频率属于武器而不是警卫类型

- 状态：已确认
- 日期：2026-08-25

## 决策

- 伤害、最大射程、最短射击间隔、弹匣容量和换弹时间属于武器定义。
- 警卫类型负责移动、感知、瞄准、何时扣动扳机、是否持续扣住扳机以及战术行为。
- 武器自身强制执行射速与弹匣限制，警卫 AI 不能绕过。
- 后续可以将现有警卫行为与机枪、火箭枪等武器组合，形成新的敌人配置。
- 先前提出的“手枪警卫每 0.9 秒最多射击一次”不作为警卫固有属性采用；具体频率由手枪武器定义决定。

## 设计理由

将角色行为与装备能力分离，避免每新增一种持枪警卫就复制射击数值和逻辑。

## 尚未决定

- 同名武器在玩家与敌人手中是否完全共享数值
- 手枪、机枪和火箭枪的最终射击间隔
- 警卫对自动武器采用多长的点射与停顿
