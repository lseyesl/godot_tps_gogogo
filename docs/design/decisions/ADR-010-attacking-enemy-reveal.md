# ADR-010：敌人攻击后短暂暴露

- 状态：已确认
- 日期：2026-08-25

## 已确认决策

- 盲区中的敌人仍可按照自身感知与攻击规则对玩家发起攻击。
- 敌人射击后会短暂暴露身影，使玩家能够定位并反击。
- 暴露状态持续 2 秒，结束后如果敌人仍不在玩家有效视野内，则再次隐藏。
- 攻击暴露可以绕过玩家 120° 视野的朝向限制，但不能绕过实体障碍物的遮挡。
- 敌人与玩家之间仍有无遮挡直线时，即使敌人位于玩家背后，也显示高亮身影。
- 敌人在暴露期间进入墙后，实时身影立即隐藏，并在最后暴露位置留下短暂、静止且不会跟踪移动的提示。
- 每次射击都会把攻击暴露的剩余时间刷新为 2 秒。
- 连续射击的敌人会持续暴露，并在最后一发射出 2 秒后重新隐藏。
- 攻击暴露只显示实际开火敌人的高亮身影与枪口火光。
- 攻击者周围的盲区不会被点亮，附近其他敌人、武器和动态内容不会因此显形。

## 设计作用

让 120° 视野之外的攻击保持威胁，同时给玩家提供有限时效的反击窗口。

## 明确不采用

- 穿墙追踪敌人实时位置
- 通过一次攻击揭示攻击者周围的其他盲区内容
