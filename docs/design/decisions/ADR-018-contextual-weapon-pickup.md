# ADR-018：安全拾取自动执行，换枪需要确认

- 状态：已确认
- 日期：2026-08-25

## 决策

- 拾取武器槽为空时，靠近武器会自动拾取。
- 靠近与槽内武器相同的武器且备用弹药未满时，自动拾取并补充弹药。
- 靠近不同类型武器时，显示临时“交换”按钮；只有玩家点击后才替换武器。
- 当前武器弹药已满时，不消耗同类武器拾取物。
- 被替换武器仍按既定规则掉在玩家脚下并保留剩余弹药。

## 设计理由

减少常规补给操作，同时避免移动经过武器堆时误换武器或浪费资源。

## 尚未决定

- 交换按钮的位置与触发距离
- 急救包是否沿用相同的自动拾取原则
