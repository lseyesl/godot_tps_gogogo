# ADR-004：敌人使用视线、声音与最后已知位置

- 状态：已确认
- 日期：2026-08-25

## 决策

敌人通过以下信息发现和追踪玩家：

1. **视线**：敌人视线会被墙体等障碍物遮挡；看见玩家后进入追击或攻击状态。
2. **声音**：枪声、爆炸声会在一定范围内惊动敌人。敌人只获知声源位置，不会因此持续掌握玩家的当前坐标。
3. **最后已知位置**：丢失视线后，敌人会前往玩家最后一次被目击的位置搜索；在一段时间内未重新发现玩家后恢复巡逻。

## 约束

- 障碍物对感知的遮挡必须实际参与敌人判定。
- 听觉不能等同于透视或永久锁定玩家。

## 尚未决定

- 敌人视野距离、角度与反应时间
- 各类声音的传播范围以及墙体是否削弱声音
- 搜索持续时间与巡逻路线规则
