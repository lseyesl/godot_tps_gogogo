# ADR-072：点击武器图标切换武器

- 状态：已确认
- 日期：2026-08-25

## 决策

- HUD 右上角显示默认手枪与拾取武器槽两个武器图标。
- 点击对应图标直接切换到该武器。
- 当前装备武器使用高亮状态表示。
- 当前武器图标附近显示弹匣与备用弹药。
- 特殊武器总弹药耗尽时自动切回默认手枪。
- 空弹药特殊武器仍保留在拾取武器槽中，可通过同类武器拾取补充弹药。

## 设计理由

提供明确、低误触的双武器切换方式，并避免特殊武器耗尽时玩家停留在无法射击的状态。
