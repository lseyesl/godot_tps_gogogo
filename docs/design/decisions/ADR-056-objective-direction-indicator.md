# ADR-056：HUD 显示目标方向与大致距离

- 状态：已确认
- 日期：2026-08-25

## 决策

- 关卡开始后，屏幕边缘显示指向任务点的方向箭头。
- 指示器显示玩家到当前目标的大致距离。
- 指示器不绘制通往目标的路径，也不自动选择路线。
- 任务点激活后，同一指示器改为指向出生点撤离区域。
- 目标指示器是任务信息，不会使沿途墙后敌人、武器或其他动态内容显形。

## 设计理由

控制 120° 视野下的无目的兜圈时间，守住 5–8 分钟目标时长，同时保留通道选择、开墙和战斗决策。

## 尚未决定

- 距离显示使用数字还是近、中、远分级
- 指示器与剩余敌人数的具体 HUD 布局
