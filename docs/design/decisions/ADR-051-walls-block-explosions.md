# ADR-051：墙体阻挡爆炸且同次爆炸不穿透

- 状态：已确认
- 日期：2026-08-25

## 决策

- 爆炸对目标结算伤害前，检查爆心与目标之间是否存在完整隔板模块。
- 只要存在阻挡，墙后的玩家、敌人或其他目标不受该次爆炸伤害。
- 作为阻挡物的可损坏隔板模块自身仍然承受爆炸伤害。
- 即使阻挡模块被本次爆炸摧毁，本次爆炸也不会继续穿过新缺口伤害其后的目标。
- 后续独立爆炸可以穿过已经形成的缺口。

## 设计理由

让砖墙和可损坏墙在爆炸发生时都能提供可靠掩护，并避免单次爆炸的结算顺序造成难以预测的多层穿透。

## 尚未决定

- 爆炸与模块边缘接触时的遮挡容差
- 爆炸是否造成击退
