# ADR-081：地图与相关设计强制遵循体验多样性规范

- 状态：已确认
- 日期：2026-09-04

## 决策

- 新增并强制执行 [`体验多样性设计规范`](../EXPERIENCE-VARIETY-STANDARD.md)。
- 后续地图、房间、遭遇、内容生成、敌人布置、掩体、可破坏物、危险物、武器、补给、任务与撤离节奏设计必须通过该规范的结构、可玩与自动验证门禁。
- 每次实质修改必须提交“房间—遭遇—主要决策—解法—成本—奖励—激活后变化”矩阵。
- 设计多样性的判定以决策变化为准，不以坐标、美术或敌人数量变化为准。
- 无法满足强制项时必须新增 ADR，不得以普通数值调优绕过。

## 设计理由

当前系统已经具备视野、锁定、掩体、可破坏墙、燃烧、爆炸、特殊武器、任务和撤离，但如果这些系统彼此独立散布，玩家仍可能持续使用“探视野、锁定、开枪”的单一解法。随机位置能够改变目标出现地点，却不必然改变路线、资源取舍或战术决策。

建立统一规范可以让现有系统围绕不同战术问题组合，优先提高每个房间的决策密度和整局节奏，而不是依赖新增大量内容掩盖基础重复。

## 影响

- 补充 ADR-025、ADR-034 与 ADR-080 对手工地图、随机内容和房间优先 CQB 拓扑的约束，不推翻其现有结论。
- 当前地图后续修改前需要建立遭遇矩阵并完成至少 5 个不同种子的可玩审计。
- 内容候选点将逐步补充房间职责、遭遇职责、风险和环境关联信息。
- 自动测试应逐步覆盖可结构化的模板标签与连续重复限制；主观节奏继续由人工可玩测试验证。
- 本决策不增加第二种敌人、第二张地图、刷怪、倒计时或新的任务类型，因此不改变当前 MVP 的明确不做范围。
