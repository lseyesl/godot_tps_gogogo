# ADR-080：首版地图采用房间优先的 CQB 拓扑

- 状态：已确认
- 日期：2026-08-28

## 决策

- 60×40 米地图先由不可破坏砖墙划分为 12 个局部房间，再在房间内部布置少量静态掩体与可破坏隔板。
- 房间使用错位门洞连接，避免形成贯穿整张地图的连续射线；门洞至少保留两个连续的 2 米导航格。
- 地图保留左右两条主要循环路线，不使用单走廊串联所有房间。
- 随机警卫、任务、武器与急救包候选点必须位于开放格，并全部从出生点可达。
- 出生庭院、任务激活与返回撤离闭环、23 段可破坏墙和环境连锁预算保持不变。

## 设计理由

原布局主要在大平面中摆放短墙和散落掩体，虽然能截断部分射线，但玩家仍会频繁面对宽阔开放面。先建立房间骨架，可以让 8 米射程、8–10 米视野和近距离瞄准锁定稳定落在单个或相邻房间内；错位门洞和循环路线同时保留绕侧与撤退选择，避免变成单线迷宫。

## 影响

- 取代此前以中央长墙、外围 L 形墙和散落掩体为主的地图分区方式。
- 房间墙、室内掩体、房间锚点和门洞锚点由独立 `cqb_room_layout_3d.tscn` 管理。
- 自动回归新增房间骨架数量、门洞开放、房间邻近结构和全部随机候选点可达性检查。
- 2 米导航格、相机、移动速度、视野、射程、敌人预算与随机生成算法不变。
