# ADR-075：盲区环境效果只提供间接反馈

- 状态：已确认
- 日期：2026-08-25

## 决策

- 盲区中的火焰不显示精确位置或完整火区特效。
- 盲区中的爆炸不直接显示完整特效。
- 玩家仍能听见具有大致方向的燃烧声与爆炸声。
- 盲区爆炸可以短暂照亮玩家当前有效视线中的墙面或场景表面。
- 间接光照不会使盲区中的敌人、武器或其他动态单位显形。
- 火区进入玩家有效视线后才显示完整效果。
- 攻击暴露仍然只显形实际开火的敌人，不受环境闪光扩大。

## 设计理由

维持“镜头覆盖不等于角色看见”的信息边界，同时确保大型环境事件在盲区发生时仍有可感知反馈。
