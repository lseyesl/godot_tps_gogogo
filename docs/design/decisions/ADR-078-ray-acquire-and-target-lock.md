# ADR-078：射线选敌后持续锁定

- 状态：已确认
- 日期：2026-08-28

## 决策

- 右侧瞄准摇杆控制一条从当前枪口出发的选择射线。
- 射线靠近玩家有效视野内、无遮挡且处于当前武器射程内的敌人时，自动吸附并建立持续锁定。
- 松开瞄准摇杆后保留锁定；玩家朝向、120° 视野方向、瞄准虚线和实际射击方向持续跟随目标。
- 再次将瞄准射线滑向其他有效敌人时切换锁定；明显滑向空白方向时解除锁定并恢复手动朝向。
- 敌人死亡、离开武器射程或持续被遮挡/离开有效视野时解除锁定；短暂遮挡提供 0.2 秒宽限，避免墙角闪烁。
- 射击键只负责开火，不再通过拖动改变朝向。半自动武器每次按下发射一发，机枪按住连续射击。
- 锁定不会自动开火，也不会让火箭转向或追踪；火箭只在发射瞬间采用当前锁定方向。
- 相机继续使用固定斜俯视跟随，不因锁定目标发生独立旋转或缩放。

## 设计理由

双摇杆加独立射击键仍要求右拇指在瞄准与开火之间频繁切换。持续锁定把高精度方向维持交给系统，玩家只需用右摇杆选择目标，再用射击键决定开火时机，同时保留受限视野、墙体遮挡、射程和弹药管理的战术边界。

## 取代范围

- 取代 ADR-006 中“按住射击键并拖动调整朝向”的交互。
- 取代 ADR-007 中“仅做轻度方向修正且不锁定”的交互。
- 不改变 ADR-007 的不透墙、不锁定盲区目标和不自动开火原则。
