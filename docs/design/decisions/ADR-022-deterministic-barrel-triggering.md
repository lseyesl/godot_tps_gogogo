# ADR-022：油桶使用确定性的耐久触发

- 状态：已确认
- 日期：2026-08-25

## 决策

- 石油滚筒墙受到任何武器或爆炸伤害，耐久归零后进入燃烧状态，不会立即消失。
- 汽油滚筒墙受到任何武器或爆炸伤害，耐久归零后立即爆炸并消失。
- 汽油滚筒墙接触传播来的火焰时立即爆炸。
- 火箭爆炸可以直接触发石油滚筒墙燃烧和汽油滚筒墙爆炸。
- 默认手枪也能逐步削减两种滚筒墙的耐久并最终触发它们。
- 首版不使用随机点燃或随机爆炸概率。

## 设计理由

让环境连锁反应可以观察、学习和规划，并确保玩家只持有默认手枪时仍能使用全部核心环境机制。
