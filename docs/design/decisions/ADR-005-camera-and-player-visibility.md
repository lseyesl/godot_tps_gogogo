# ADR-005：采用高位斜俯视第三人称镜头

- 状态：已确认
- 日期：2026-08-25

## 决策

- 镜头位于玩家角色上方偏后，以固定方位的高位斜俯视角跟随角色位置，而非贴肩越肩镜头或正交顶视镜头。
- 镜头不会随着角色朝向或瞄准方向旋转。
- 右摇杆只旋转角色朝向、瞄准方向与 120° 视野扇形，地图在屏幕上的方位保持稳定。
- 地图采用适合平面移动与隔板分区的空间结构。
- 摄像机即使拍到某片区域，只要该区域不在角色的有效视线内，其中的敌人与可拾取物就不会显示。
- 有效视线同时受距离与障碍物遮挡限制。

## 设计理由

- 保持第三人称空间感，同时提高迷宫式地图、爆炸范围和可破坏隔板的可读性。
- 防止高机位绕过角色感知，让受限视野继续具有战术价值。

## 尚未决定

- 视线外场景的具体表现方式
- 输入设备与瞄准方式
