# ADR-029：激活任务点后撤离

- 状态：已确认
- 日期：2026-08-25
- 取代：ADR-002“采用关卡清剿目标”

## 决策

单关采用两阶段目标：

1. 玩家进入地图后寻找并激活任务点。
2. 任务点激活时，所有仍存活的警卫进入警戒并开始搜索玩家。
3. 玩家随后到达撤离点即获胜。

玩家不需要消灭全部敌人。玩家死亡仍然导致本局失败。

## 设计理由

- 避免纯清剿模式中最后一名敌人难以找到的问题。
- 去程以探索和路线规划为主，回程以警戒、追逐和突围为主。
- 杀敌成为降低撤离风险和获取路线优势的手段，而不是机械的清单要求。
- 随机武器、可破坏隔板、环境连锁和受限视野仍然直接影响任务完成方式。

## 尚未决定

- 任务点与撤离点的布局关系
- 激活任务点所需时间及是否能被攻击打断
- 警卫进入全局警戒后掌握的信息精度
- 剩余敌人数是否继续显示
