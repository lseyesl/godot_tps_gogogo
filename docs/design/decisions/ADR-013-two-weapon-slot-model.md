# ADR-013：永久手枪加一个拾取武器槽

- 状态：已确认
- 日期：2026-08-25

## 决策

- 默认单发手枪永久保留，不能被拾取武器替换掉。
- 玩家另有一个拾取武器槽。
- 玩家可以在默认手枪与拾取武器之间切换。
- 拾取另一把特殊武器时，新武器替换拾取武器槽中的旧武器。
- 被替换的武器连同剩余弹药掉落在玩家脚下，可在之后重新拾取。

## 设计理由

- 确保玩家始终拥有基础战斗能力，不会因随机生成或特殊武器耗尽而无法清关。
- 单一拾取槽迫使玩家在机枪、火箭枪等武器之间做选择。
