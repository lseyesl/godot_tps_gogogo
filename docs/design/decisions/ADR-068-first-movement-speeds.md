# ADR-068：首轮玩家与警卫移动速度

- 状态：已确认，数值待可玩测试调优
- 日期：2026-08-25

## 决策

| 单位状态 | 移动速度 |
| --- | ---: |
| 玩家基础移动 | 5.0 米/秒 |
| 警卫巡逻 | 2.5 米/秒 |
| 警卫调查或搜索 | 3.2 米/秒 |
| 警卫追击 | 4.0 米/秒 |

玩家在所有移动方向使用同一 5.0 米/秒速度。警卫速度由当前 AI 状态决定。玩家曾在触控响应调优中提高到 6.0 米/秒；按约 1 米角色尺度复测后回调为 5.0 米/秒。

## 设计理由

玩家比 4.0 米/秒的追击警卫快 25%，可以通过正确路线逐步摆脱追踪；跑过 2 米地图模块需要 0.4 秒，避免 6.0 米/秒时穿越掩体和攻击范围过快。转向观察、交火和绕墙仍会缩小该优势。
