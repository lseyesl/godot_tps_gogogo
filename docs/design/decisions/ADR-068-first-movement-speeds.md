# ADR-068：首轮玩家与警卫移动速度

- 状态：已确认，数值待可玩测试调优
- 日期：2026-08-25

## 决策

| 单位状态 | 移动速度 |
| --- | ---: |
| 玩家基础移动 | 4.5 米/秒 |
| 警卫巡逻 | 2.5 米/秒 |
| 警卫调查或搜索 | 3.2 米/秒 |
| 警卫追击 | 4.0 米/秒 |

玩家在所有移动方向使用同一 4.5 米/秒速度。警卫速度由当前 AI 状态决定。

## 设计理由

玩家略快于追击警卫，可以通过正确路线逐步摆脱追踪；转向观察、交火和绕墙仍会缩小该优势。

## 尚未决定

- 受击、换弹和燃烧伤害是否影响速度
- 加速与减速曲线
