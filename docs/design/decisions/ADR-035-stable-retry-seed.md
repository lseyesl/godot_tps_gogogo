# ADR-035：重试保留随机结果，新游戏重新随机

- 状态：已确认
- 日期：2026-08-25

## 决策

- 开始新游戏时生成一个新的随机种子。
- 该种子决定本局的敌人、任务点、武器和急救包位置。
- 玩家死亡后选择“重试”时继续使用同一随机种子，所有开局随机内容恢复为该局最初状态。
- 玩家返回主菜单并选择“新游戏”时才重新生成种子与内容分布。

## 设计理由

让玩家能够从失败中学习敌人分布、资源位置和路线选择，同时让主动开始的新游戏保持变化。

## 尚未决定

- 是否向玩家显示或允许输入随机种子
- 通关后再次游玩是默认重试该种子还是生成新种子
- 被破坏地图和已消耗资源在重试时的重置表现
