# ADR-069：警卫将火区视为临时不可通行

- 状态：已确认
- 日期：2026-08-25

## 决策

- 格子路径图将正在燃烧并造成伤害的格子标记为临时不可通行。
- 警卫不会主动规划穿过火区的路线。
- 如果唯一通路正在燃烧，警卫会在安全位置等待或执行当前可用的搜索行为。
- 火焰熄灭后，对应格子重新开放并允许重新规划。
- 玩家不受 AI 规则限制，可以自行决定承受伤害穿过火区。

## 设计理由

避免只有 3 点生命的警卫明显自杀，并让玩家能够用火焰暂时封锁敌人路线。

## 尚未决定

- 警卫是否会主动远离即将发生连锁爆炸的汽油桶
- 多条安全路线之间的危险代价比较
