# ADR-049：首轮隔板耐久基准

- 状态：已确认，数值待可玩测试调优
- 日期：2026-08-25

## 决策

| 隔板模块 | 耐久 | 耐久归零结果 |
| --- | ---: | --- |
| 木墙 | 5 | 模块被摧毁并打开缺口。 |
| 石油滚筒 | 4 | 进入燃烧状态，燃烧结束后消失。 |
| 汽油滚筒 | 3 | 立即爆炸并消失。 |
| 砖墙 | 无限 | 不受首版任何伤害影响。 |

由此产生的基准效果：

- 标准手枪需要命中木墙 5 次、石油滚筒 4 次或汽油滚筒 3 次。
- 爆心伤害为 5 的火箭可以直接摧毁单个木墙模块。
- 重型手枪和机枪按其武器伤害与射速削减相同耐久。

## 设计理由

使用简单整数建立容易理解的破坏效率，并让火箭枪拥有明确的一发开洞能力。

## 尚未决定

- 爆炸对多个相邻模块的实际伤害分布
- 隔板受击反馈与耐久可视化
- 燃烧持续时间与持续伤害
