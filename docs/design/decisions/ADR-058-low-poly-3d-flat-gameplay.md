# ADR-058：低多边形三维表现与纯平面玩法

- 状态：已确认
- 日期：2026-08-25

## 决策

- 游戏采用简洁的低多边形 3D 画面。
- 玩家、警卫、墙体、滚筒、武器和火箭都使用真实 3D 对象表现。
- 角色移动、敌人寻路、视野计算、枪械射线和内容生成都基于同一水平玩法平面。
- 首个可玩版本不加入跳跃。
- 首个可玩版本不加入地形高低差、多层建筑或上下层战斗。

## 设计理由

保留第三人称空间感、墙体破坏和爆炸效果，同时限制几何与判定复杂度，适配 Android 性能目标。
