# ADR-070：警卫每发射击前锁定方向零点二秒

- 状态：已确认
- 日期：2026-08-25

## 决策

- 警卫首次发现玩家后仍先执行 0.6 秒首次攻击预警。
- 警卫准备每次射击时可以先跟踪玩家位置。
- 每发射击前最后 0.2 秒，警卫停止修正瞄准方向。
- 射击射线沿锁定方向发出。
- 武器自身继续强制最短射击间隔；标准手枪当前为 0.45 秒。
- 首版不使用隐藏的随机命中率决定警卫是否命中。

## 设计理由

让玩家通过持续横移或进入掩体确定性规避部分即时射线攻击，同时让站桩行为承担稳定风险。

## 尚未决定

- 锁定期间是否显示玩家可见的细微举枪动画
- 未来机枪或火箭警卫是否使用不同锁定时间
