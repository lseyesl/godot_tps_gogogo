# ADR-024：隔板按模块逐段独立破坏

- 状态：已确认
- 日期：2026-08-25

## 决策

- 所有隔板由统一宽度的独立模块排列组成。
- 每个可损坏模块拥有独立耐久与状态。
- 一段木墙被摧毁时，只移除对应模块并打开该宽度的缺口；相邻模块继续存在。
- 石油滚筒墙和汽油滚筒墙由单个滚筒模块组成，每个滚筒独立燃烧、爆炸或消失。
- 模块被移除后，该位置对移动、射击和视线开放。

## 设计理由

支持精准开洞、射击口与新路线，并将视野和寻路更新限制在实际发生变化的位置。

## 尚未决定

- 标准模块的世界尺寸
- 角色能否穿过单模块缺口
- 破坏后导航网格的更新时间与表现
- 相邻模块是否承受溅射或结构伤害
