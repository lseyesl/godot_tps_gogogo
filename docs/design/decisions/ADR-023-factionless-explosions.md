# ADR-023：爆炸不区分阵营并具有距离衰减

- 状态：已确认
- 日期：2026-08-25

## 决策

- 火箭与汽油滚筒墙爆炸使用统一的范围伤害原则。
- 爆炸可以伤害玩家、敌人和范围内的可损坏隔板，不区分伤害来源或阵营。
- 爆炸伤害随目标到爆心的距离增加而衰减。
- 爆炸可以使汽油滚筒墙耐久归零并引发连锁爆炸，也能触发石油滚筒墙燃烧。
- 砖墙免疫所有爆炸伤害。

## 设计理由

让强力范围武器伴随近距离自伤风险，并允许玩家或敌人利用环境连锁反应消灭对方。
