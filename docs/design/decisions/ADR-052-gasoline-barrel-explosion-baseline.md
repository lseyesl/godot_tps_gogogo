# ADR-052：汽油滚筒爆炸基准

- 状态：已确认，数值待可玩测试调优
- 日期：2026-08-25

## 决策

- 汽油滚筒爆炸半径为 1.5 个隔板模块。
- 爆心伤害为 3 点，足以直接击杀满生命手枪警卫。
- 爆炸边缘伤害为 1 点，中间区域按距离衰减。
- 对可损坏隔板使用相同的距离衰减伤害。
- 汽油桶爆炸可以触发附近汽油滚筒或石油滚筒的耐久状态变化。
- 单个汽油桶爆炸不能一击摧毁满耐久 5 点的木墙。
- 火箭爆炸仍然更强：半径 2 个模块、爆心 5 点。

## 设计理由

让汽油桶具有击杀与连锁战术价值，同时保留有限弹药火箭枪作为更强的范围破坏工具。
