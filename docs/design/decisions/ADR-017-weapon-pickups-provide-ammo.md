# ADR-017：通过同类武器拾取补充弹药

- 状态：已确认
- 日期：2026-08-25

## 决策

- 首个可玩版本不生成独立弹药箱。
- 每个地图武器拾取物自带该武器的固定弹药量。
- 玩家拾取与当前拾取武器槽相同的武器时，补充该武器的备用弹药。
- 玩家拾取不同类型的武器时，新武器替换拾取武器槽中的旧武器。
- 被替换武器会掉在玩家脚下，并保留被替换时的剩余弹药。
- 默认手枪弹药无限，不需要地图补给。

## 设计理由

- 让地图中重复生成的武器仍有价值。
- 降低随机生成与资源平衡的对象种类。
- 保持有限弹药武器的稀缺性和路线选择价值。

## 尚未决定

- 每类武器拾取时提供的弹药量
- 备用弹药上限
- 弹药已满时能否消耗拾取物
- 不同武器的确认拾取交互
