# ADR-065：二维格子寻路与三维移动表现

- 状态：已确认
- 日期：2026-08-25

## 决策

- 敌人路径规划使用与隔板模块对齐的二维格子图。
- 隔板模块存在时，对应通行格处于阻塞状态。
- 隔板模块移除时，开放对应通行格并触发受影响警卫重新规划。
- 警卫最终仍是 3D 角色，在世界水平面中沿格子路径进行平滑移动。
- 首版不在运行时重新烘焙整张三维导航网格。

## 设计理由

地图、移动和破坏都基于单一平面与模块结构，格子路径更新更加直接、确定，并更容易控制 Android 上的性能成本。

## 尚未决定

- 格子与隔板模块的实际世界尺寸
- 斜向移动和拐角裁切规则
- 火区等临时危险对寻路代价的影响
