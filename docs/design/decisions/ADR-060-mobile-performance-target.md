# ADR-060：默认六十帧并提供三十帧选项

- 状态：已确认
- 日期：2026-08-25

## 决策

- 首版以中端 Android 设备稳定 60 FPS 为主要性能目标。
- 设置中提供锁定 30 FPS 的省电选项。
- 标准压力场景包含最多 12 名预置警卫、燃烧、爆炸、动态视野和模块破坏。
- 火焰粒子、爆炸效果、阴影与视野遮罩必须在标准压力场景下服从目标帧率。

## 设计理由

双摇杆瞄准和即时射线射击受益于高帧率，同时保留 30 FPS 选项以适配续航或性能更弱的设备。
