# ADR-011：首版只实现手枪警卫

- 状态：已确认
- 日期：2026-08-25

## 决策

首个可玩版本只实现一种敌人：手枪警卫。

手枪警卫装备与玩家永久默认武器相同的标准手枪，并共享该武器的伤害、射程、射速、弹匣与换弹数值。

手枪警卫具备以下行为：

- 按路线巡逻。
- 听见枪声或爆炸后前往声源位置调查。
- 看见玩家后寻找可用掩体并以手枪单发射击。
- 丢失视线后搜索玩家最后已知位置。
- 搜索未果后恢复巡逻。

## 暂不纳入首个可玩版本

- 使用机枪的敌人
- 使用火箭枪的敌人
- 其他敌人职业或特殊能力

## 设计理由

用一个行为完整的基准敌人验证视野、听觉、攻击暴露、掩体和基础枪战，再决定后续敌人差异。

## 尚未决定

- 标准手枪的射击间隔、弹匣与换弹数值
- 巡逻路线生成方式
- 掩体选择与换位规则
- 是否拥有弹药限制
