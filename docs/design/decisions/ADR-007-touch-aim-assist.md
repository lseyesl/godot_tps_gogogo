# ADR-007：采用轻度触屏瞄准辅助

- 状态：已确认
- 日期：2026-08-25

> 2026-08-28 更新：轻度方向修正已由 ADR-078 的射线选敌与持续锁定取代；不透墙、不锁定盲区目标和不自动开火原则继续有效。

## 决策

- 对瞄准虚线附近的敌人提供小幅方向修正。
- 瞄准辅助只对玩家有效视线内的敌人生效。
- 瞄准辅助不能锁定障碍物后方或视野外的敌人。
- 瞄准辅助不会替玩家自动开火。

## 设计理由

补偿 Android 触控瞄准的精度限制，同时保留手动操作、视野遮挡与探索带来的战术价值。

## 尚未决定

- 多个候选目标之间的选择规则
- 不同武器是否使用不同的辅助强度
