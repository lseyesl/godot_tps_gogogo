# ADR-019：常规枪械即时命中，火箭使用实体弹道

- 状态：已确认
- 日期：2026-08-25

## 决策

- 默认手枪、重型手枪和机枪使用即时射线判定命中。
- 火箭枪发射场景中可见、具有飞行时间的实体火箭。
- 实体火箭可以被玩家观察和躲避。
- 实体火箭与墙体或角色发生碰撞时引爆。

## 设计理由

- 即时命中让 Android 触控下的常规射击保持直接响应。
- 火箭的飞行时间为躲避、预判、墙体破坏和环境连锁反应提供空间。

## 尚未决定

- 即时射线的散布与射程衰减
- 火箭速度、爆炸半径与自伤规则
- 子弹和火箭对各种隔板的效果
- 敌人是否能够射击或引爆飞行中的火箭
