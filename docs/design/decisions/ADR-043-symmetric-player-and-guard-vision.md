# ADR-043：玩家与警卫使用相同视野几何

- 状态：已确认
- 日期：2026-08-25

## 决策

- 手枪警卫的视觉范围是以自身朝向为中心的 120° 扇形。
- 警卫视觉半径为 8 个隔板模块。
- 警卫视线受到与玩家相同的障碍物遮挡。
- 玩家与警卫的视觉角度、距离和实体遮挡原则完全一致。
- 警卫的感知差异只来自听觉、巡逻、搜索状态与 AI 反应时间，不通过额外视距获得优势。

## 设计理由

建立可学习、可预测的对称视觉规则，保证敌人不会在玩家武器与视野范围外依靠超长视觉单方面发现并攻击玩家。
