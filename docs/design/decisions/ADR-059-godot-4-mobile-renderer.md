# ADR-059：使用 Godot 4 与 Mobile 渲染器

- 状态：已确认
- 日期：2026-08-25

## 决策

- 首个可玩版本使用 Godot 4 开发。
- 3D 渲染使用面向移动设备的 Mobile 渲染器。
- 首要发布与测试平台为 Android 横屏设备。
- 武器、警卫配置、隔板与关卡候选点应采用可复用的数据驱动方式组织。

## 设计理由

Godot 4 能覆盖中小规模低多边形 3D 场景、射线感知、导航、模块化破坏和 Android 导出，并与当前纯平面玩法范围匹配。

## 尚未决定

- 具体 Godot 4 小版本
- 最低 Android 系统版本与图形 API
- 性能目标与质量档位
