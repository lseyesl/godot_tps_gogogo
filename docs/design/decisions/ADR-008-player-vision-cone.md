# ADR-008：玩家采用 120° 扇形视野

- 状态：已确认
- 日期：2026-08-25

## 决策

- 玩家有效视野是以角色朝向为中心的 120° 扇形，即朝向左右各 60°。
- 视野具有有限半径。
- 墙体等障碍物会遮挡扇形内的视线，在障碍物后形成不可见区域。
- 角色朝向同时影响观察方向与射击方向。

## 选择理由

相较 360° 有限视野，120° 扇形视野要求玩家主动转向、搜角和预瞄，使背后成为真实盲区，并提高伏击与探索时的紧张感。

## 接受的风险

- Android 双摇杆的观察负担更高。
- 敌人从盲区攻击可能让玩家感到不公平。

后续需要通过脚步、叫声、攻击前摇等可感知信号控制这种风险，但具体声音与预警规则尚未确认。
