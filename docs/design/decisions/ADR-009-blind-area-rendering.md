# ADR-009：盲区保留暗化地形并隐藏动态单位

- 状态：已确认
- 日期：2026-08-25

## 决策

- 玩家盲区中的静态地形与墙体仍然显示。
- 盲区内的静态场景明显暗化并降低饱和度，以区别于有效视野。
- 盲区内的敌人、武器拾取物及其他动态威胁完全隐藏。
- 区域进入有效视野后恢复正常亮度，其中的动态单位才会显示。

## 设计理由

保留地图结构能降低高位镜头下的导航负担；隐藏动态信息则避免玩家利用摄像机位置获得角色本不应知道的墙后情报。

## 尚未决定

- 已见过与从未探索过的区域是否使用不同表现
- 子弹、火焰、爆炸等动态环境效果在盲区中的显示规则
- 盲区敌人能否以及如何攻击玩家
