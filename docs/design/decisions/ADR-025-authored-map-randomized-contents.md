# ADR-025：手工地图布局与随机内容生成

- 状态：已确认
- 日期：2026-08-25

## 决策

- 首个可玩版本的墙体、通道和房间布局由设计者手工制作。
- 敌人、武器和急救包只会在预先标记并验证过的候选出生点中随机放置。
- 首版不使用完全程序生成的墙体布局。

## 设计理由

- 保证 120° 视野下的遭遇公平性。
- 避免动态开墙和爆炸连锁与随机布局组合后产生死路、无解位置或开局连锁事故。
- 允许设计者验证每个出生点的路线、遮挡与资源关系。

## 后续方向

核心战斗稳定后，可考虑使用经过验证的房间模块进行拼接生成，而不是任意随机放置墙体。

## 尚未决定

- 首版地图数量与单关目标时长
- 各类内容的数量和出生点约束
- 随机种子是否对玩家可见或可重玩
