# ADR-061：首轮声音传播范围

- 状态：已确认，数值待可玩测试调优
- 日期：2026-08-25

## 决策

| 声音事件 | 警卫可听半径 |
| --- | ---: |
| 玩家脚步 | 2 模块 |
| 标准手枪 | 12 模块 |
| 重型手枪 | 14 模块 |
| 机枪 | 14 模块 |
| 木墙摧毁 | 10 模块 |
| 火箭或汽油桶爆炸 | 20 模块 |
| 持续燃烧 | 4 模块 |

附加规则：

- 首版声音按水平面圆形距离传播，不计算墙体隔音或衰减。
- 警卫听见声音时只获得声源位置，不会因此获得玩家实时位置。
- 玩家通过立体声获得盲区声音的大致方向，不显示精确声源坐标。

## 设计理由

建立清晰的声音强度层级，让开火、破坏和爆炸能够改变附近敌人状态，同时将首版实现限制为可预测的距离判定。

## 尚未决定

- 声音事件持续时间与重复合并规则
- 无障碍功能中的方向性声音视觉提示
