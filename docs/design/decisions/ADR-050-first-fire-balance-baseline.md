# ADR-050：首轮燃烧平衡基准

- 状态：已确认，数值待可玩测试调优
- 日期：2026-08-25

## 决策

- 石油滚筒点燃后持续燃烧 4 秒，随后消失。
- 木墙被火焰点燃后持续燃烧 3 秒，随后摧毁并打开缺口。
- 木墙燃烧期间仍然阻挡移动、射击和视线。
- 火区每秒对其中的玩家或敌人造成 1 点伤害。
- 单位离开火区后立即停止受到火焰伤害，不附带角色持续灼烧状态。
- 直接相邻的可燃模块接触火焰后，立即进入各自的燃烧或爆炸状态。

## 设计理由

用短促、确定的状态建立封路和连锁玩法，不额外引入角色身上的持续灼烧状态与解除机制。
