# ADR-064：动态破坏系统更新时序

- 状态：已确认
- 日期：2026-08-25

## 决策

- 隔板模块消失的同一帧移除其物理碰撞。
- 射击射线与玩家、警卫视线在同一帧使用更新后的障碍状态。
- 使用该模块作为掩体的警卫立即判定掩体失效并重新选择行为。
- 敌人导航路径最迟在模块移除后 0.2 秒内完成更新。
- 视觉模型消失与物理碰撞移除必须保持一致；不允许角色被看不见的旧碰撞阻挡。

## 设计理由

保证开墙后射击与观察立即生效，同时允许导航更新合并连续爆炸造成的多次变化，避免同步重建带来的帧率尖峰。
