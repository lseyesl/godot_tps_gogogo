# ADR-044：警卫首次攻击前预警零点六秒

- 状态：已确认
- 日期：2026-08-25

## 决策

- 手枪警卫首次发现玩家后不会立即开枪。
- 警卫先用 0.6 秒转向并举枪。
- 首次攻击准备期间播放可辨别大致方向的警戒声。
- 0.6 秒结束后，警卫才能射出第一发。
- 第一发射出后触发既定的 2 秒攻击暴露。
- 同一次持续交战中不重复播放完整的首次攻击警告。

## 设计理由

为 120° 视野盲区中的首次袭击提供短暂、可学习的反应窗口，同时保持背后威胁。

## 尚未决定

- 警卫手中武器的射击间隔（由武器定义负责）
- 举枪期间瞄准是否持续跟随玩家
- 警戒声传播距离与字幕或视觉辅助
